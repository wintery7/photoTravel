# photoTravel   

   
## 📱 프로젝트 소개   

"PhotoTravel"은 여행 기록과 일정 계획을 간편하게 관리할 수 있는 애플리케이션입니다. 더불어, 특별한 순간을 하나의 화면에서 모아 보는 기능을 제공합니다.
